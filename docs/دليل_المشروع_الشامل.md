## 1. إيه هو نؤطة ولمين

**نؤطة (No2ta)** شبكة اجتماعية وتعاون خاصة بفصل مدرسي، بتشتغل بالكامل على شبكة LAN محلية (من غير إنترنت ضروري للوظائف الأساسية). جهاز واحد (جهاز المدرّس/الأدمن) بيشغّل السيرفر، وكل باقي أجهزة الفصل (طلاب) بيدخلوا عليه من المتصفح بنفس الشبكة.

**الفكرة الأساسية:** مساحة تواصل وتعاون للفصل فيها:
- شات عام وخاص وجروبات، ستوريز، AirDrop لمشاركة الملفات فورًا.
- سبورة تفاعلية مشتركة وكشكول أكواد حي (Live CodePad).
- بث شاشة بين الطلاب، موسيقى ومكتبة قرآن متزامنة لكل الفصل.
- أدوات دينية: تسبيح إلكتروني جماعي، تذكير "صلِّ على محمد" صوتي لكل الأجهزة، مواقيت الصلاة.
- **"زر البشمهندسة" (Panic Button، F2):** زر إخفاء فوري لكل الفصل — بيغطي الشاشة بامتحان/كويز تفاعلي حقيقي (مش مجرد صورة وهمية) في حالة دخول أي معلّم غير متوقع. الفكرة إن الطلاب بيستخدموه بشكل جماعي وقت المذاكرة مع بعض، مش غش فردي.
- أدوات إدارة ومراقبة معمل (NetSupport-style): الأدمن يقدر يشوف شاشات الطلاب، يقفل الأجهزة، يبعت رسائل عامة.
- لعبة تنافسية لحظية (تحدي الرياضيات السريع).

**المستخدمين:** معلّم واحد بدور "أدمن" (بيتحدد بالماك أدرس الفيزيائي لجهازه، مش بباسورد)، وبقية الفصل "طلاب" بيدخلوا بكلمة سر مشتركة + اسم مستعار يختاروه.

## 2. البنية التقنية

| الطبقة | التقنية الفعلية |
|---|---|
| السيرفر | Node.js + Express 5 + Socket.IO 4 (نقطة الدخول: `server.js`) |
| قاعدة البيانات | SQLite (عبر `sqlite3`)، الجداول والاتصال في `data/db.js` |
| الواجهة | HTML/JS خام (من غير React/Vue) — `public/index.html` + `public/js/app.js` (~6700 سطر) |
| الشكل | Tailwind CSS (CDN) + Lucide Icons (CDN) + `design-tokens.css` + `style.css` |
| رفع الملفات | Multer، التخزين في `uploads/` |
| الصوت المتزامن | HTML5 Audio + حساب `currentTime` من السيرفر لمزامنة كل الأجهزة |
| بث الشاشة | WebRTC (`getDisplayMedia` + `RTCPeerConnection`)، الإشارات عبر Socket.IO |
| مراقبة المعمل | `html2canvas` في المتصفح (خفيف) أو PowerShell Agent لقطة سطح مكتب كاملة |
| اكتشاف الشبكة | UDP Broadcast (`services/discovery.js` + `services/discover-host.ps1`) |
| التشغيل | `Start_No2ta.bat` (أدمن أو طالب حسب الماك)، `Fix_Firewall.bat` |

**لا يوجد** build step ولا bundler ولا framework — كل حاجة بتتحمل من CDN أو ملفات ثابتة، والسيرفر بيتشغل مباشرة بـ `node server.js`.

## 3. خريطة الملفات

```
نؤطة/
├── server.js                      ← كل الـ REST routes + Socket.IO handlers (آلاف الأسطر)
├── data/
│   ├── db.js                      ← تعريف جداول SQLite وتهيئتها
│   └── quran-reciters.js          ← مكتبة القرّاء (8 قراء) من mp3quran.net
├── services/
│   ├── network.js                 ← استخراج IP/MAC، فحص الأدمن
│   ├── discovery.js                ← بث UDP بيعلن "أنا هنا" كل 2 ثانية (Server-side)
│   └── discover-host.ps1          ← سكريبت PowerShell بيسمع البث ده (Client-side)
├── public/
│   ├── index.html                 ← الصفحة الوحيدة (SPA)، فيها كل الـ 20+ مودال
│   ├── js/app.js                  ← كل منطق الواجهة (state, rendering, sockets)
│   ├── css/
│   │   ├── style.css              ← أنماط عامة (Glassmorphism، الخ)
│   │   └── design-tokens.css      ← متغيرات نظام التصميم (الألوان، الخطوط...)
│   ├── stealth/physics.html       ← محتوى "زر البشمهندسة" (امتحان فلاتر تفاعلي)
│   └── agent/                     ← نسخة مُقدَّمة من install-student-agent.bat + lab-agent.ps1
├── uploads/                       ← ملفات مرفوعة (صور، صوت، AirDrop، كاش موسيقى/قرآن)
├── docs/                          ← كل التوثيق (الملف ده من ضمنها)
├── Start_No2ta.bat                ← نقطة التشغيل الرئيسية (أدمن/طالب حسب الماك)
├── install-student-agent.bat      ← تثبيت صامت لـ Agent مراقبة المعمل
├── lab-agent.ps1                  ← سكريبت التقاط شاشة الطالب الكامل
└── Fix_Firewall.bat               ← فتح البورت في الفايروول يدويًا لو لازم
```

## 4. كل صفحة وميزة بالتفصيل

### 4.1 تسجيل الدخول (Auth Modal)
كلمة سر مشتركة واحدة (`SdSdSdSd`) + اسم مستعار يختاره الطالب + افتار (رفع صورة شخصية حقيقية أو اختيار إيموجي من 6 خيارات). الأدمن بيتعرف تلقائيًا من الماك أدرس — مش محتاج كلمة سر مختلفة.

### 4.2 الشات
- **شات عام** لكل الفصل، **شات مباشر** بين طالبين، **جروبات** (عامة أو خاصة تحتاج موافقة).
- رسائل نصية، صور/فيديو/ملفات، كود/نص خام (Code Snippet)، رسائل صوتية.
- رسائل تختفي تلقائيًا (Disappearing messages) باختيار مؤقت.
- Streaks (تواصل يومي متتالي بين طالبين) مع تجميد تلقائي في الويك إند.
- إشعارات سطح مكتب + تنبيه في عنوان التبويب لو فيه رسالة جديدة.

### 4.3 الاستوريز
نشر صورة/فيديو/نص يختفي، حلقة لونية حوالين الأفاتار تفرّق بين "شوفتها" و"لسه"، عداد مشاهدات حي.

### 4.4 AirDrop
مشاركة ملفات فورية لكل الفصل من غير إنترنت — اسحب أي ملف وهيظهر لكل الأجهزة المتصلة بنفس الشبكة يحملوه فورًا.

### 4.5 السبورة التفاعلية (Whiteboard)
رسم حر مشترك لحظيًا بين كل الفصل، 5 ألوان + ممحاة، تصدير كصورة.

### 4.6 كشكول الأكواد (Live CodePad)
مساحة نص/كود واحدة مشتركة لحظيًا لكل الفصل (زي Google Docs بسيط)، نسخ كل المحتوى بضغطة، إرسال المحتوى للشات.

### 4.7 بث الشاشة (Screen Share)
أي طالب يقدر يبث شاشته لباقي الفصل (WebRTC)، مع تحكم في الصوت، ملء الشاشة، نافذة عائمة (PiP).

### 4.8 مكتبة القرآن الكريم 🆕
بدل الراديو الحي القديم (اللي كان بيتقطع ومش متزامن)، دلوقتي فيه **8 قراء حقيقيين** (المنشاوي، عبد الباسط، الحصري، السديس، العفاسي، المعيقلي، محمد أيوب، ياسر الدوسري) من مصدر رسمي مجاني (`mp3quran.net`). أي حد يختار قارئ وسورة ويبثها لكل الفصل، والتشغيل **متزامن فعليًا** بين كل الأجهزة (مش بس بيبدأ مع بعض، فيه تصحيح مستمر كل 20 ثانية لأي جهاز "يزحلق"). فيه كمان زرار "تشغيل عندي بس" لسماعها بمفردك من غير بث للفصل.

### 4.9 الموسيقى والراديو
بحث أونلاين عن أي أغنية (3 مصادر احتياطية: JioSaavn، مصدر ثاني، ثم Deezer كمعاينة 30 ثانية لو الاتنين فشلوا)، رفع أغاني محلية لمكتبة الفصل، تشغيل متزامن لكل الأجهزة.

### 4.10 التسبيح الإلكتروني
عداد تسبيح شخصي + إجمالي جماعي للفصل كله، أصوات بشرية حقيقية لكل ذكر، هدف قابل للتخصيص (33/100/∞).

### 4.11 "صلِّ على محمد" (صوت متزامن)
أي حد يضغط الزرار، وكل أجهزة الفصل بتنطق "اللهم صلِّ على محمد" بصوت بشري حقيقي في نفس اللحظة تقريبًا (فرق أجزاء من الثانية بسبب سرعة الشبكة بس).

### 4.12 مواقيت الصلاة وجدول اليوم الدراسي
حساب دقيق لمواقيت الصلاة بالإسكندرية (حسابات فلكية حقيقية مش API خارجي)، وجدول الحصص والبريك وفترة البايونيك والمرواح بتوقيت حي.

### 4.13 "زر البشمهندسة" (Panic Button — F2)
أهم ميزة أمان/خصوصية في التطبيق. ضغطة F2 (أو Esc مرتين) من أي جهاز بتخفي الشات فورًا على **كل** أجهزة الفصل وتستبدله بصفحة امتحان حقيقية تفاعلية (حاليًا محتوى "Flutter Competency"، 71+ سؤال، إجابات نموذجية). الإخفاء بيتفك إما محليًا بكلمة سر على جهاز واحد بس، أو عالميًا لكل الفصل من جهاز الأدمن.

**🆕 الامتحان بقى له درجات حقيقية**: لما الطالب يخلّص كل الأسئلة، درجته بتتحفظ في قاعدة البيانات تلقائيًا، وفيه **لوحة متصدرين** (زرار 🏆 في الهيدر) بتعرض: أعلى درجة اليوم، أعلى درجة على الإطلاق، وأفضل 10 نتائج.

### 4.14 مراقبة المعمل (NetSupport-style، للأدمن فقط)
شاشة تعرض كل أجهزة الفصل لحظيًا (التقاط خفيف بالمتصفح أو برنامج PowerShell كامل)، قفل/فتح الأجهزة، رسالة عامة لكل الشاشات، عرض شاشة طالب واحد بالتفصيل.

### 4.15 لوحة تحكم الأدمن
إحصائيات الفصل، بث إذاعة عامة، تفعيل وضع التركيز (قفل الشات وقت الشرح)، إدارة المستخدمين.

### 4.16 🆕 تحدي الرياضيات السريع (لعبة تنافسية)
لعبة لحظية حقيقية عبر Socket.IO: 8 أسئلة حساب متتالية تظهر لكل المتصلين في نفس اللحظة، أول واحد يكتب الإجابة الصح ياخد نقطة، لوحة نقاط حية، ونتيجة نهائية. أي حد يقدر يبدأ جولة من زرار "تحدي سريع" في الهيدر.

## 5. قاعدة البيانات

SQLite، الجداول (في `data/db.js`):

| الجدول | الغرض |
|---|---|
| `users` | المستخدمين (اسم، افتار، دور، جهاز) |
| `messages` | كل رسائل الشات (عام/خاص/جروب) |
| `message_reactions` | تفاعلات الرسائل |
| `stories` | الاستوريز |
| `story_views` | مين شاف كل استوري |
| `streaks` | سلاسل التواصل اليومي بين الطلاب |
| `airdrop_files` | ملفات AirDrop |
| `groups` / `group_members` / `group_join_requests` | الجروبات وأعضاءها وطلبات الانضمام |
| `music_library` | مكتبة الأغاني المحلية والمؤقتة |
| `system_settings` | إعدادات عامة (وضع التركيز، حالة الإخفاء...) |
| 🆕 `quiz_scores` | درجات امتحان "البشمهندسة" + لوحة المتصدرين |

## 6. الصلاحيات والأمان

- **الأدمن** يتحدد بـ MAC أدرس فيزيائي واحد ثابت في `server.js` — مش بتسجيل دخول حقيقي.
- **الطلاب** كلهم بكلمة سر مشتركة واحدة — مفيش حسابات فردية موثوقة.
- ⚠️ هذا نموذج "ثقة الشبكة المحلية" (LAN trust) مناسب لفصل مدرسي صغير، **مش نظام أمان حقيقي** — أي حد عنده الباسورد المشترك يقدر يدخل باسم أي حد.
- تم حل مشكلة كانت موجودة: رسالة خطأ كلمة السر كانت بتكشف الباسورد الحقيقي كامل في نص الخطأ — اتصلحت.

## 7. نظام التصميم (Midnight & Brass v1.1)

التفاصيل الكاملة في `docs/DESIGN_SYSTEM.md`. ملخص سريع:

- **الهوية:** خلفية غرافيت دافئة شبه سودة (مش أزرق بارد)، لون أساسي واحد **دهبي/براص** (Brass Gold) بدل الألوان المتفرقة القديمة.
- **لا إيموجي في الواجهة الوظيفية إطلاقًا** — كل الأزرار والعناوين والحالات بقت أيقونات **Lucide** حقيقية. الإيموجي محصور بس في محتوى شخصي يختاره الطالب (الأفاتار، أيقونة الجروب).
- **الهيدر** منظم في 3 مجموعات منطقية (أدوات تعاون / بث وروحانيات / هوية)، وزر "البشمهندسة" معزول دايمًا في الآخر.
- **دروب داونز مخصصة** بدل شكل المتصفح الافتراضي.
- هذا الاتجاه اتختار بعد ما المستخدم راجع 3 بدائل بصرية فعلية (`docs/design-direction-preview-v2.html`) واختار "ليلي وبراص".

## 8. تاريخ التعديلات — إيه اللي اتعمل وليه

### الجلسة الأولى: الدراسة ونظام التصميم
1. دراسة شاملة للتطبيق بالكامل وتوثيقها (`docs/NO2TA_APP_STUDY.md`).
2. إصلاح إذاعة القرآن الحية (أول نسخة): بناء relay على السيرفر نفسه عشان يتخطى فايروول المدرسة اللي كان بيمنع الموقع الخارجي.
3. بناء نظام تصميم v1.0 ("Ink Blue + Teal") — **اترفض من المستخدم** لما شافه فعليًا ("الألوان دي مش عاجباني").
4. 3 اتجاهات بصرية بديلة اتعرضت، واختار المستخدم "ليلي وبراص" (Midnight & Brass) → النظام الحالي v1.1.

### الجلسة الثانية: التطبيق الفعلي (الجلسة دي)
طلب المستخدم شامل جدًا — قائمة طويلة من المشاكل والتطويرات، مع تفويض كامل للعمل من غير مراجعة خطوة بخطوة ("انا هروح المدرسه... كمل وخلص وارفع الجيت هاب"). اتعمل بالترتيب:

1. **باگ الـ IP الثابت** — كان `Start_No2ta.bat` بيفتح دايمًا على `192.168.20.54:5000` مهما كان الـ IP الحقيقي للأدمن. اتبنى نظام اكتشاف تلقائي عبر بث UDP (السيرفر يعلن مكانه كل ثانيتين، والطالب يسمع ويتصل تلقائي) + كاش لآخر عنوان معروف كـ fallback.
2. **مكتبة القرآن المتزامنة** — استبدال البث الحي الهش بـ 8 قراء حقيقيين من `mp3quran.net`، مع إعادة استخدام نظام المزامنة الموجود + نبضة تصحيح كل 20 ثانية + تقدم تلقائي للسورة التالية + زرار تشغيل شخصي.
3. **إصلاحات UI**: الشعار، أيقونة AirDrop، صندوق اختيار الأفاتار، شبكة مواقيت الصلاة الجانبية (كانت 5 أعمدة متكدسة، بقت 3)، ضغط أزرار الهيدر لأيقونات في الشاشات الأصغر.
4. **تحسين الـ Autoplay** — "صلِّ على محمد" والأذكار كانوا ممكن يفشلوا بصمت على أجهزة معينة بسبب سياسة المتصفح؛ دلوقتي بيتفكوا تلقائيًا أول ما حد يلمس الصفحة.
5. **تحسين بحث الأغاني** — إضافة Deezer كمصدر ثالث احتياطي.
6. **امتحان "البشمهندسة" بدرجات** — حفظ الدرجة في قاعدة البيانات + لوحة متصدرين.
7. **دروب داونز مخصصة** — بدل شكل المتصفح الافتراضي.
8. **تحدي الرياضيات السريع** — أول لعبة تنافسية حقيقية (من أصل خطة أكبر لعدة ألعاب، اتعمل واحدة شغالة 100% بدل عدة ألعاب نص مشتغلة).
9. **دفعتين من شيل الإيموجي** من الهيدر، الواجهة الرئيسية، وأغلب الموداللز (AirDrop، السبورة، الكشكول، التسبيح، الجروبات، الاستوري، صلِّ على محمد، بث الشاشة، الموسيقى).
10. اتلقت واتصلحت **3 باگات حقيقية** من نفس النوع: جافاسكريبت كان بيكتب فوق أيقونة Lucide جديدة بإيموجي قديم عند تغيير الحالة (أيقونة كتم صوت بث الشاشة، زرار صوت التسبيح، مؤشر تزامن الكشكول) — اتصلحوا باستخدام أيقونتين مخفي/ظاهر بدل استبدال النص.

## 10. المشاكل والخطوات الباقية

> التفاصيل الكاملة والترتيب في `docs/ROADMAP_NEXT.md`.

1. **إيموجي لسه باقي** في: تفاصيل مودال الأدمن الكامل، تفاصيل NetSupport العميقة، بعض رسائل `showNotification` المؤقتة. الأماكن الأكتر ظهورًا يوميًا (الهيدر، الشات، الموداللز الرئيسية) خلصت.
2. **الألعاب التنافسية** — اتعملت لعبة واحدة بس (تحدي الرياضيات). باقي أفكار زي سباق الكتابة (Typing Race)، خمّن الكلمة، تريفيا — ممكن تتضاف بنفس النمط.
3. **مراجعة شاملة للباگات** — تم اختبار فعلي للميزات الأساسية (دخول، شات، AirDrop، القرآن، الدروب داونز، الامتحان، اللعبة)، لكن مفيش وقت لاختبار كل ميزة بالتفصيل (الستوريز الكاملة، الجروبات بكل سيناريوهاتها، NetSupport الكامل، السبورة).
4. **بحث الأغاني** — ما فيش API مجاني موثوق "يجيب أي أغنية من أي حتة" فعليًا (سبوتيفاي وساوند كلاود قافلين الوصول المجاني من زمان). اللي موجود دلوقتي (3 مصادر احتياطية) هو أحسن حل مجاني متاح، لكن مش مضمون 100%.
5. **رسالة console قديمة في `Start_No2ta.bat`** — سطر العرض بيقول "📡 رابط السيرفر: http://192.168.20.54:5000" وده نص ثابت قديم (مش بيأثر على الاتصال الفعلي، بس بيطلع رقم غلط للأدمن يقراه — يستحق تنضيف بسيط.

## 11. ملاحظات مهمة لأي حد يكمل الشغل

- **نظام التصميم** (`docs/DESIGN_SYSTEM.md`) هو المرجع الوحيد للألوان/الخطوط/المسافات — ممنوع إضافة قيمة تصميم جديدة من غير ما تتوثق هناك الأول.
- **ممنوع استخدام إيموجي كأيقونة وظيفية** في أي كود جديد — استخدم Lucide (`<i data-lucide="...">`) ونادِ `renderIcons()` بعد أي تحديث DOM ديناميكي.
- ⚠️ **تنبيه مهم عند تحديث أي عنصر `textContent`/`innerHTML` بالـ JavaScript**: لو العنصر ده فيه أيقونة Lucide بالفعل، **متستبدلش النص كله** وإلا هتمسح الأيقونة. استخدم نمط "أيقونتين مخفي/ظاهر" (زي `tasbeehSoundIconOn`/`tasbeehSoundIconOff`) بدل تبديل النص.
- **مفيش git commit** إلا لما الشغل يتختبر فعليًا في المتصفح (مش بس `node --check`).
- المكتبة الصوتية للقرآن بتتخزن محليًا في `uploads/quran/` (مش جزء من git — اتولّد تلقائيًا أول مرة تتشغل سورة).
