05 / PRINCIPLES
  • لون أخضر أساسي واحد، مع خلفيات ورقية؛ البرتقالي لمسات محدودة.
  • مفيش توهج أو تدرجات على كل عنصر، ولا حركة مستمرة للزينة.
  • Lucide للأيقونات الوظيفية؛ إيموجي المستخدم يفضل محتوى شخصي.
  • الاسم ظاهر بجانب الأداة المهمة، والأيقونات المنفردة لها وصف لقارئ الشاشة.
  • المسافات ٤، ٨، ١٢، ١٦، ٢٤، ٣٢، ٤٨. البطاقات والمودالات ٢٠ بكسل انحناء، والحقول والأزرار ١٢.
  • الشاشات القديمة تُنقل تدريجيًا إلى المكونات الجديدة؛ تفعيل الألوان وحدها مش إعادة تصميم.
